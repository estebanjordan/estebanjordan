## 💼 Portafolio Web

Este repositorio contiene mi portafolio profesional desarrollado en **React.js**.

### Características

- Diseño responsivo adaptable a todos los dispositivos
- Animaciones fluidas con CSS y JavaScript
- Secciones interactivas con filtros por categoría
- Timeline horizontal de trayectoria académica
- Barras de progreso animadas para habilidades

### Instalación

```bash
# Clonar el repositorio
git clone https://github.com/estebanjordan/portafolio.git

# Navegar al directorio
cd portafolio

# Instalar dependencias
npm install

# Ejecutar en modo desarrollo
npm start
```

### Despliegue

| Plataforma | Método |
|------------|--------|
| **Vercel** | Conectar repositorio de GitHub |
| **Netlify** | Arrastrar carpeta `build` |
| **GitHub Pages** | Usar `gh-pages` para publicar |
